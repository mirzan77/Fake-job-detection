# Fake Job Posting Detection using Machine Learning

## Project Overview
This project detects fake job postings using machine learning and NLP techniques.

## Methodology
- Data preprocessing (cleaning, stopword removal, lemmatization)
- TF-IDF feature extraction
- SMOTE for handling imbalance
- Logistic Regression and Random Forest models

## Models Used
- Logistic Regression
- Random Forest

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-Score
