# Fake Job Posting Detection using Machine Learning

## 📌 Overview
This project detects fraudulent job postings using machine learning and NLP techniques.

## ⚙️ Technologies Used
- Python
- Scikit-learn
- TF-IDF
- SMOTE
- Logistic Regression
- Random Forest

## 📊 Features
- Text preprocessing (cleaning, stopwords removal, lemmatization)
- Feature extraction using TF-IDF
- Handling imbalanced data using SMOTE
- Fraud classification (Real / Fake)

## 📁 Project Structure
- data/ → dataset (sample)
- models/ → trained models
- notebooks/ → Jupyter notebooks
- outputs/ → results

## 🚀 Results
Logistic Regression showed balanced performance with good accuracy and recall.

## ⚠️ Note
Due to size limitations, only a sample dataset is included.
